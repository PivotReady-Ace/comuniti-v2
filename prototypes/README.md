# Prototypes Archive

This folder contains prototype components and experimental code that are not currently used in the application but may be valuable for future reference.

## Contents

### AmbassadorDirectory.tsx
- **Original Purpose**: Advanced ambassador directory with ratings, reviews, service tags, and filters
- **Status**: Prototype with 31 TypeScript errors due to interface mismatches with database schema
- **Archived Date**: August 5, 2025
- **Reason**: Unused in routing, replaced by AmbassadorDirectorySimple.tsx which uses real API data
- **Features**: Mock data, complex UI components, identity reviews, referrer tracking
- **Future Use**: Could be adapted for a full directory listing page or enhanced individual profiles

## Usage Note
Files in this folder are excluded from the build process and should not be imported into active components.
